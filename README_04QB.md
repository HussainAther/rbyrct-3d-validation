# Experiment 04Q-B — Frozen adaptive acquisition with cross-projector measurements

## Research question
Does the representable/subvoxel reversal documented in 04P persist when synthetic X-ray line integrals are generated by the **04Q-A trilinear midpoint ray-marching** projector rather than by the prior Siddon-like fine-grid projector?

## Model separation
- Measurements: `experiment_04qa.project` on the full fine-grid phantom; trilinear center-sample interpolation; finite-step midpoint integration. All online policies see only the generated observation vector through their existing acquired-only access mechanisms.
- Reconstruction and online provisional models: unchanged coarse `experiment_04b.system_matrix` and `experiment_04j.sirt_silent`.
- Frozen policies: `experiment_04j.adaptive_order` strength=1 and strength=0; `experiment_04g.policies` geometry balanced; `experiment_04h.voxel_coverage_order`; `experiment_04oc.online_order` with original gate threshold=2, gate_strength=0.
- Diagnostic-only comparator: fine-grid Siddon-like operator `experiment_04m.high_resolution_matrix`. Its projections are NEVER used in acquisition/reconstruction.
- Truth: replicated version uses the coarse phantom voxel-wise repeated; subvoxel uses independently analytic fine-grid phantom with block-averaged reconstruction target.

## Installation
Unzip the package at the top level of your existing `rbyrct-3d-validation` directory, retaining all current `experiment_04*.py` modules. This bundle contains only the new experiment and test, and README. It requires `experiment_04qa.py` from the earlier 04Q-A patch as well as the original 04P + 04O-C dependencies.

```powershell
conda activate rbyrct-3d
python -m unittest -v test_experiment_04qb.py
```

## Pilot: 40 reconstructions
```powershell
python experiment_04qb.py `
  --size 16 --angles 12 --factor 2 `
  --phantoms branches pores `

  --offsets 0 `

  --budgets 1024 2048 `
```

## Outputs
- `metrics.csv`: RMSE and cross-model relative projection error per policy/scenario.
- `paired_cases.csv`, `paired_summary.csv`: gain = (feedback-off RMSE - policy RMSE) / feedback-off RMSE, paired within phantom, representation, offset, seed, noise, and budget.
- `mismatch_diagnostics.csv`: `relative_projection_mismatch` against coarse Siddon projections, and `relative_projector_disagreement` against fine Siddon simulations, computed **offline**.
- `gate_trace.csv`: prospective gate's acquired-only diagnostics and chosen feedback strengths.
- `timing.csv`: selection and reconstruction execution times (not a formal performance benchmark).
- `protocol.json`: complete run configuration and limitations.

## Interpretation and safeguards
- Positive gain means lower RMSE than feedback-off at the **same acquired ray count**.
- For trilinear measurements, even replicated objects are not exactly matched to piecewise-constant coarse Siddon reconstruction. Treat the name `replicated` as **object representation**, not exact forward-model identity.
- Offset, seed and budget cases share phantom families and are not statistically independent objects. Use per-phantom results when analyzing generalization.
- Do not tune thresholds or change selectors after looking at the pilot and call that unchanged confirmation; if making exploratory changes, document them separately.
- Ray-marching uses same declared parallel-ray coordinate geometry and a different numerical interpolation/integration model, **not independent physical X-ray science**. No dose, hardware, or clinical validation.
- Numerical step choice must remain frozen (0.25 coarse units, as in 04Q-A). Include later fine-step convergence checks if needed.
