# 08AJ-E: no-outcome integration preflight (draft)

This package integrates **existing** RBYRCT sparse geometry, the unchanged diagonal-information selector, the historical coverage and stratified selectors, the 08AJ-B uniform multiscale and 08AJ-C complete-view selectors, the 04QA independent ray-marching forward projector, and the unchanged 05B MART implementation.

**Only engineering fixtures are run.** This is not the 24-object confirmatory experiment, does not calculate gains, and does not freeze the protocol. The 8^3 smoke fixture is deliberately separate from all 08AJ-D test seeds.

## Install

Copy these three files beside your existing `experiment_08aj_d.py` and other experiment modules:

- `experiment_08aj_e.py`
- `test_experiment_08aj_e.py`
- `README_08AJ_E.md`

Dependencies: existing RBYRCT project Python environment (NumPy/SciPy/pytest).

## Exact integration boundaries

- The common catalogue uses `experiment_04b.system_matrix` with tilt-major, then azimuth, then detector-row/column order.
- `same` generates clean measurements from `A @ coarse_truth`.
- `independent` uses `experiment_04qa.project` with `factor=2`, `step=0.5`, and trilinear interpolation over fine samples. This is **independent forward-projection arithmetic** but uses the **same underlying synthetic object family and seed**, not an independently collected dataset.
- The fine phantom is built at `2n` using the new 08AJ-D generator; the *adapter* coarse truth is its block mean at `n`. **This does not match** the `truth_sha256` generated by the current 08AJ-D draft's direct `phantom(family, seed, n)` call. The truth-definition/hash rule must be reconciled, then the manifest regenerated **before** any lock. Do not reinterpret existing hashes as the new truth.
- Exactly one synthetic noisy measurement catalogue is generated per object/seed/model fixture; selected measurements are indexed by each policy's ray IDs. The current fixture does not claim the final noise-pairing scheme is frozen.
- `information_diag` uses a common `coverage` warm history; the other policies do not. Shared-prefix fairness is an open design choice.
- Complete detector views require `budget % (n*n) == 0`; feasible in the `8^3, budget=128` fixture and `32^3, budget=2048` study, but not for `64^3, budget=2048`.
- The fixture performs a two-epoch MART numerical-validity check for **one** selected order, no object RMSE, no comparative reconstruction, no gain, and no new 24-object results.

## Required steps before protocol freeze

1. Reconcile how coarse and fine truth are generated and update the **draft** manifest, preserving all previously generated files as draft evidence.
2. Confirm proposed phantom families are sufficiently distinct from earlier source objects and validate the forward mismatch calibration.
3. Decide and test warm-history fairness, resource ceilings, 32^3 production budgets, and reproducible noise pairing.
4. Specify complete-view secondary comparison handling at each resolution.
5. Implement a complete resumable 24-object production driver with pre-run lock verification and failure policy, plus an independent audit.
6. Review statistical assumptions and the protocol, then source-lock and commit **before** computing confirmatory outcomes.

The `PREFLIGHT_PASS` verdict is only an engineering-integration result.
