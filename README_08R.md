# RBYRCT-08R package

A literature and novelty audit for the 08OP manuscript. No code changes, no new simulation outcomes, and no changes to the frozen 08M/08Q archives.

- `08R_LITERATURE_NOVELTY_AUDIT.md` — mathematical derivation, closest precedents, claim boundaries, and prioritized next comparisons.
- `08R_NOVELTY_MATRIX.csv` — structured comparison of acquisition unit, information objective, measurement feedback, and evidence.
- `08R_MANUSCRIPT_POSITIONING.md` — draft abstract, contribution statement, related-work transition, reviewer risks.

Usage: extract into a documentation subfolder of the repository (e.g. `docs/08r/`) or another research-note directory. Review and correct citations against full papers before submission. This review is based on accessible abstracts and publisher/institutional records and is not a completed systematic literature review. The RBYRCT results are reported from prior experiment logs and audits supplied in conversation; archived source files were not re-audited in this task.

Recommended next milestone: 08S manuscript expansion, but incorporate at least one closely matched A-optimal / reduced-dimensional comparator first or candidly identify it as outstanding.
